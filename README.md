# 🎲 ProyectoDados

Este proyecto es una aplicación interactiva que simula el lanzamiento de dados. Está desarrollado como parte de una práctica de programación colaborativa utilizando Git y GitHub.

## 🚀 Objetivos del proyecto

- Simular el comportamiento de dados virtuales
- Practicar el uso de ramas, commits y pull requests en Git
- Aplicar principios de diseño responsivo y lógica de programación

## 🛠️ Tecnologías utilizadas

- HTML, CSS, JavaScript
- Git y GitHub para control de versiones
- Visual Studio Code como editor principal
